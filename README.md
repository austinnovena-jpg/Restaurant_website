## ✨ Features

### Core Features
- **🛒 Interactive Shopping Cart** - Add, remove, and update item quantities with real-time updates
- **📱 Fully Responsive Design** - Optimized for all devices from mobile to desktop
- **🎨 Modern UI/UX** - Clean, intuitive interface with smooth animations
- **🔍 Smart Menu Browsing** - Category filtering and grid/list view toggle
- **💳 Secure Checkout Process** - Multi-step checkout with payment options
- **📝 Order Customization** - Special instructions and dietary preferences
- **🎁 Promo Code System** - Apply discount codes with validation
- **💾 Local Storage Persistence** - Cart items saved across sessions

### Human-Centric Design
- **❤️ Warm, Inviting Tone** - Friendly messaging throughout the experience
- **📖 Storytelling Elements** - Personal chef's notes and brand story
- **👨‍🍳 Personal Touches** - Chef signatures, team bios, and customer testimonials
- **😊 Emoji & Icon Integration** - Visual warmth without hardcoded images
- **🎯 Emotional Connection** - Design choices that make users feel welcomed

### Technical Features
- **🚀 Pure Vanilla JavaScript** - No frameworks, lightweight and fast
- **📦 Modular Code Structure** - Organized, maintainable JavaScript
- **🎨 Custom CSS** - Well-commented, organized stylesheets
- **🔧 No External Dependencies** - Only Font Awesome for icons
- **♿ Accessibility Ready** - Semantic HTML and ARIA attributes
- **🖨️ Print-Friendly** - Optimized styles for printing menus and orders

## 🎨 Design Philosophy

This project was built with a **human-first approach**, focusing on creating an experience that feels warm, welcoming, and personal. Every design choice—from the color palette to the typography—was made to evoke feelings of comfort, trust, and delight.

### Color Psychology
- **Purple Gradients (#667eea → #764ba2)** - Creativity, trust, and warmth
- **Green Gradients (#11998e → #38ef7d)** - Freshness, growth, and health
- **Warm Accents** - Gold (#ffd93d) and coral (#f5576c) for emotional connection

### Typography
- **Poppins** - Modern, clean, and readable for body text
- **Playfair Display** - Elegant, sophisticated for headings
- **Dancing Script** - Personal, handwritten feel for special messages

### Personality
- Friendly, conversational tone
- Personal stories and chef's notes
- Emojis and icons that add warmth
- Customer testimonials and team bios

## 🛠️ Technologies Used

### Frontend
- **HTML5** - Semantic markup for accessibility and SEO
- **CSS3** - Custom styling with Flexbox, Grid, and animations
  - Variables for consistent theming
  - Media queries for responsiveness
  - Keyframe animations for interactions
- **JavaScript (ES6+)** - Dynamic functionality
  - DOM manipulation
  - Event handling
  - Local storage management
  - Form validation

### Third-Party Libraries
- **Font Awesome 6** - Icon library (CDN)
- **Google Fonts** - Custom typography (CDN)

### Development Tools
- **VS Code** - Recommended editor with Live Server extension
- **Git** - Version control
- **Chrome DevTools** - Testing and debugging
